# Минимальный пример подключения экспортированной темы

Пример подготовлен для стека LePear: React, shadcn/ui Base Nova, Tailwind v4. Он не добавлен в маршруты приложения и не запускался агентом. Проверка интеграции остаётся частью ручной приёмки MYT-13.

1. В редакторе настройте **оба** режима и скачайте CSS. Сохраните его как `src/lepear-theme.css` в проекте для проверки.
2. В основном stylesheet после импортов Tailwind/shadcn подключите:

```css
@import "./lepear-theme.css";
```

Файл содержит директиву `@theme inline` и должен проходить через Tailwind v4. Это исходный CSS для сборки, не готовый stylesheet для вставки в `<style>` без компиляции. Отдельные глобальные значения `:root` файл не задаёт: значения тем ограничены `.lepear-theme`. Стандартный dark-вариант проекта должен работать по классу `.dark`, как в LePear. Меняйте **и** класс `dark`, **и** `data-theme` на одном контейнере. Светлый вложенный scope внутри тёмного предка требует dark-вариант с исключением `[data-theme="light"]`, как в текущем `src/index.css` LePear.

3. Для Geist импортируйте существующий пакет отдельно:

```css
@import "@fontsource-variable/geist";
```

Если пакета нет, установите его в целевом проекте. Остальные семейства в текущем наборе — шрифты устройства с fallback; CSS не поставляет их файлы.

4. Скопируйте `ThemeIntegrationExample.tsx` в `src` и подключите компонент в своей странице/маршруте. Используются уже имеющиеся в LePear Button, Card, Input, Label и Dialog. В другом проекте нужны эти shadcn-компоненты и alias `@`.
5. `DialogContent portalContainer={scope}` использует расширение локальной обёртки LePear. В стандартной обёртке shadcn передайте этот ref в `<DialogPrimitive.Portal container={...}>` (Base UI), либо вынесите scoped-тему в контейнер, который включает и портал. Аналогично нужно размещать портал Select внутри корня темы. Без этого портал в `body` не наследует scoped CSS-переменные.
6. В целевом проекте вручную выполните его обычную сборку и откройте пример. Сравните две палитры, шрифт/кириллицу, насыщенности/интервалы, радиусы, высоты, отступы, длинную кнопку и диалог. Проверьте Tab/hover/disabled и узкую ширину. Эти проверки агентом не выполнялись.

Для JSON round-trip скачайте JSON из редактора, измените настройки и импортируйте скачанный файл. До «Применить тему» состояние не меняется. После применения сравните настройки и повторный JSON; обе палитры и все исходные параметры должны совпасть. Пробуйте испорченный JSON/неподдерживаемую версию только на копии файла: ошибка должна оставить рабочую тему неизменной.

Экспорт содержит одну тему с двумя режимами, не всю библиотеку именованных копий. Импорт также не восстанавливает библиотеку/настройки интерфейса. Для переноса выбранной копии сначала выберите её в редакторе, затем экспортируйте JSON.

Для новых Inter/Manrope/Rubik/Noto Serif/Roboto Mono подключите пакет, указанный в комментарии экспортированного CSS, и импортируйте его wght.css в точке входа. Например, после установки @fontsource-variable/inter: import "@fontsource-variable/inter/wght.css". CSS/JSON не включают файлы шрифтов; сохраняйте лицензии при распространении.
