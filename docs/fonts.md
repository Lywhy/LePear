# Шрифты с кириллицей — MYT-48

Добавлены пять локальных variable-семейств Fontsource 5.3.0. Всего в редакторе 12 семейств; прежние семь ID и цепочки fallback сохранены.

| Семейство   | Тип          | Доступный вес | Fallback                     |
| ----------- | ------------ | ------------- | ---------------------------- |
| Inter       | Без засечек  | 100–900       | system-ui, Arial, sans-serif |
| Manrope     | Без засечек  | 200–800       | system-ui, Arial, sans-serif |
| Rubik       | Без засечек  | 300–900       | system-ui, Arial, sans-serif |
| Noto Serif  | С засечками  | 100–900       | Georgia, serif               |
| Roboto Mono | Моноширинный | 100–700       | Courier New, monospace       |

Редактор по-прежнему предлагает вес 300–700: этот диапазон входит в возможности каждого нового семейства. Подключаются normal-начертания, курсив не добавлен. Системные гарнитуры зависят от устройства: не обещаем наличие или все веса, если браузер использует замену.

Метаданные пакетов подтверждают кириллицу, латиницу и OFL-1.1. Исходные лицензии сохранены в public/font-licenses/*.txt и копируются в публикуемую сборку. Источник: пакеты @fontsource-variable/inter, manrope, rubik, noto-serif, roboto-mono. Бинарные файлы не изменялись. [Установка Fontsource](https://fontsource.org/docs/getting-started/install).

## Каталог и загрузка

- font-catalog.ts — единый каталог, стабильные font ID, CSS-цепочки, описание, веса и пакет для экспорта.
- site-theme.ts переэкспортирует прежние fontFamilies/ThemeFont; валидация автоматически допускает новые ID. Schema v2 и ключи сохранения не менялись.
- font-assets/*.ts — отложенные модули с URL WOFF2 кириллицы/латиницы и unicode-range из пакета.
- use-theme-font.ts — загрузка выбранного семейства через FontFace, общий кэш запросов и защита от устаревших async-результатов.

Новые семейства загружаются при выборе/восстановлении темы, при показе выбранной сохранённой копии или предпросмотра. Список названий не пытается отрисовать каждый новый шрифт: открытие списка не скачивает все семейства. Для выбранного нового семейства нужны два WOFF2 — normal variable для кириллицы и латиницы. Остальные языки, курсив и дополнительные оси не загружаются. Geist остаётся глобальным шрифтом оболочки, как прежде.

Пока файлы загружаются, работает fallback. В блоке образца явно показаны загрузка, успешное подключение, ошибка или системный источник. В случае ошибки интерфейс не блокируется; можно сменить семейство и вернуться или перезагрузить страницу. Переключение до завершения загрузки не возвращает старый выбранный шрифт. Загруженный файл может остаться в кэше браузера; после JSON-импорта и восстановления новые семейства подгружаются тем же механизмом.

Предпросмотр содержит русский/английский текст, цифры и отдельный образец с насыщенностью заголовков. Описание показывает категорию, доступные веса и fallback. Сезон и светлый/тёмный режим оболочки от выбранного шрифта редактора независимы.

## Экспорт

CSS/JSON содержат настройки и имя семейства, но не файлы шрифта. Комментарий в CSS и инструкция экспорта показывают пакет выбранного семейства. Пример для Inter в целевом проекте:

    pnpm add @fontsource-variable/inter

Импортировать в точке входа до CSS темы:

    import "@fontsource-variable/inter/wght.css";

Другие новые семейства подключаются аналогично. Системные варианты используют установленный шрифт/fallback и не требуют Fontsource. Вместе с распространяемыми шрифтами сохраняйте их лицензию. Не копируйте ссылки с хешированными локальными Vite URL в другой проект.

## Установка в этой сессии

Глобальная Rust-версия pnpm 12.11.2 завершилась stack overflow во время установки. Зависимости восстановлены временным JS pnpm 10.28.2 без установки глобального менеджера. Для работы в ограниченном окружении использованы локальный игнорируемый store, hoisted node_modules и копирование файлов без symlink. package.json и pnpm-lock.yaml включают пять новых пакетов; скрипты установки не выполнялись. Эта операция не является сборкой или проверкой приложения.

После изменения зависимостей перезапустите свой сервер Vite. Кэш .pnpm-store/ не должен попадать в Git.

## Ручная приёмка

Проверки агентом не запускались. Пользователю проверить:

1. В типографике все 12 семейств, компактный список, клавиатуру, 320/390 px и длинные названия.
2. Каждый новый шрифт: русский/английский образец, цифры, текст/заголовки при 300/400/700 и интервалы. Проверить реальное семейство в браузере, а не только его имя в списке.
3. Быструю смену семейств, медленную загрузку/ошибку сети, статус/fallback и отсутствие скачивания всех новых семейств при открытии списка.
4. Длинный текст, кнопки, меню и диалог предпросмотра в широком/узком виде.
5. Сохранение копии, перезагрузку, восстановление, импорт/экспорт нового и старого JSON; в CSS правильное семейство и инструкция его подключения.
6. Смена шрифта не меняет цвета/размеры и остаётся общей для двух режимов пользовательской темы; сезон оболочки независим.
7. Самостоятельно запустить pnpm lint / pnpm build по своему процессу; убедиться, что лицензии присутствуют среди публичных файлов.
