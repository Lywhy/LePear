Цель — убрать конкретные повторы и лишние операции, сохранив принятый интерфейс, API и данные пользователя. Изменения выбраны по чтению исходников; замеры скорости, сборка, линтер, тесты и браузерная проверка агентом не выполнялись.

## Границы совместимости

- Очистка имён повторяет прежний порядок: NFC → удаление U+0000–U+001F/U+007F → удаление недопустимых символов имени → крайних точек/пробелов → slice → toWellFormed.
- Пределы относятся к UTF-16: 90 для видео/аудио/конвертера, 65 для заголовка субтитров. Префиксы LePear, videoId, язык, author/auto, расширения и fallback file сохранены. trim применяется там же: к общему префиксу YouTube и к очищенному имени конвертера. Кириллица не транслитерируется.
- Конвертер по-прежнему удаляет исходное расширение перед очисткой. Язык/расширение остаются проверенными отдельными обработчиками; общий helper не заменяет их валидацию.
- YouTube/конвертер сохраняют отдельные запросы, таймауты, сообщения ошибок и state machines. Не объединяются upload, polling, session ownership, отмена процессов, TTL, лимиты или потоки выдачи файлов.
- Не менялись публичные CSS/JSON-схемы, идентификаторы пресетов и шрифтов, ключи хранения, темы и форматы API.
- Каталог не импортирует React, SVG, изображения или API-модули. Иллюстрации на главной остаются статичными. Принятые фото, размеры и адаптивность не изменены.

## Что уже предусмотрено

По исходникам Aurora уже получает отдельный lazy-import и статичный fallback, при очистке отменяет RAF, отключает observers/listeners и удаляет WebGL-ресурсы. Принудительный context loss не добавлялся. Варианты анимаций уже общие.

Выбранные веб-шрифты импортируются динамически; обещания загрузки переиспользуются, устаревший ответ не меняет состояние размонтированного компонента. Изображения уже имеют WebP srcSet, размеры и lazy loading вне hero. Палитры сезонов и каталоги пресетов/шрифтов уже отделены от UI. Эти механизмы сохранены. Дополнительные мемоизация, разбиение страниц на чанки или обновления зависимостей без доказанной причины не добавлялись.

Это оценка структуры кода, не результат профилирования. Числа ускорения/снижения памяти не заявляются.

## Ручная приёмка

Пользователь проверяет:

1. Навигацию и названия страниц; переходы из обеих групп карточек главной; прежнюю мобильную ширину фото.
2. Смену четырёх сезонов и светлого/тёмного режима, перезагрузку и восстановление. Повторный выбор текущего варианта. При запрете storage — сообщение об ошибке и возможность повторной попытки.
3. Редактор: загрузку шрифтов, пресеты, сохранение/импорт/экспорт прежних тем.
4. YouTube: метаданные, видео, аудио, субтитры, повтор после ошибки, отмену во время ожидания и уход со страницы.
5. Конвертер: аудио/изображения, загрузку, отмену/новый запуск, получение результата и истечение срока хранения.
6. Имена результатов: кириллица, пробелы, эмодзи, длинный заголовок, недопустимые символы и пустой после очистки исходник.
7. Сворачивание вкладки, возврат и остановку загрузочных/фоновых эффектов; reduced motion.
8. Сборку и линтер по собственному процессу.
