# Текстовые появления — MYT-36

Этап продолжает принятую тёмную оранжево-зелёную палитру. Изменено только появление текста оболочки. Работа блоков, Aurora и якорей относится к следующим issues.

## Общий компонент

TextReveal (src/components/motion/text-reveal.tsx) сохраняет настоящий HTML-тег p/h1/h2/h3/span, id и классы. Текст не разбивается и не дублируется для screen reader.

После замечания пользователя появление переведено на явные состояния hidden → visible через useInView, вместо малозаметных keyframes с initial=false. За 0,65 секунды opacity меняется 0 → 1, смещение 14px → 0 и blur 4px → 0. Описание появляется с задержкой 0,12 секунды. Эффект проигрывается один раз за монтирование и не меняет высоту документа.

При reduced motion и при отсутствии IntersectionObserver рендерится обычный видимый HTML. Начальное предпочтение reduced motion читается до выбора анимированного варианта, затем отслеживается Motion. Доступный текст не дублируется. Существующие React Bits-акценты сохраняются, но перечисленные пользователем заголовки имеют собственное плавное появление.

Исправлены заголовки: hero «Ваш сайт. Ваш характер.», целиком «Найдите своё. Сохраните. Используйте.», FAQ «Немного ясности перед первым цветом.», CTA «Пусть выглядит по-вашему.», «Редактор темы», YouTube «Одна ссылка. Три формата.».

## Ручная приёмка

1. Открыть главную и прокрутить все секции: пары заголовок/описание согласованы, текст плавно появляется, нет изменения высоты.
2. Прокрутить вверх/вниз повторно — текст не должен каждый раз переигрывать появление.
3. На /editor вводить значения, раскрывать группы, менять режим/пресет: статичный заголовок не перезапускается от каждого изменения, живая витрина не получила декоративных эффектов.
4. На /youtube получить данные, менять вкладки/качество, начать скачивание: заголовки не переигрываются на каждом опросе, результат и ошибки появляются обычным образом.
5. На /contact вводить текст, открыть предпросмотр, исправлять ошибки: форма и фокус остаются стабильны.
6. Проверить reduced motion, 320/390 px, клавиатуру и чтение заголовков: нет повторного озвучивания слов и скрытого содержимого.
7. Нажать якорь/изменить hash: существующие текстовые компоненты на этой странице не должны перемонтироваться.

Это сценарии для пользователя, а не результаты проверки. Сборка, линтер, тесты, браузер, API и визуальные проверки агентом не запускались.

## Интеграция с MYT-37

Внутри появляющегося блока TextReveal уступает входную анимацию ScrollReveal через BlockRevealContext. Это сохраняет один согласованный вход карточки вместе с текстом. Вне таких блоков принятый TextReveal продолжает работать самостоятельно. [Карта блоков](block-motion.md).
