# Светлый и тёмный режим LePear — MYT-53

У каждого сезона два режима: светлый и тёмный. Переключатель с солнцем/луной находится в шапке; в /settings — выбор «Светлая / Тёмная» отдельно от сезона. Выбор применяется сразу, сохраняет сезон и восстанавливается после перезагрузки. Образцы карточек отражают текущий режим.

Тёмные поверхности стали более цветными и светлыми: тёплый коричневый для осени, синий для зимы, лесной зелёный для весны и морской бирюзовый для лета. Почти чёрные подложки заменены этими оттенками. Светлые режимы используют сезонные светлые поверхности и более тёмные акценты.

## Хранение

Запись lepear.shell-settings.v1 дополнена mode:

    { "version": 1, "season": "winter", "mode": "light" }

Прежняя запись без mode восстанавливается в тёмном режиме. Сезон/режим применяются до React. При ошибках — осень/тёмный режим; при отказе сохранения оформление работает в памяти с пояснением в настройках. Пользовательские темы редактора и их CSS/JSON независимы.

Сезонные пресеты редактора получают текущие светлые/тёмные цвета сайта как отдельные ThemePalette. Сохранённые пользовательские темы не переписываются; обновлённые цвета применяются явным выбором пресета.

## Реализация

shell-seasons.ts содержит тёмные наборы и выбор по season/mode, light-shell-palettes.ts — четыре светлых набора. shell-settings.ts хранит выбор, shell-palette.ts применяет токены, класс dark на html, color-scheme и theme-color. shell-mode-toggle.tsx — доступная кнопка в шапке.

Постоянные классы dark убраны из оболочки и её порталов, предпросмотр редактора продолжает задавать свой режим. Для границ/разделителей/подсветки оболочки добавлен --shell-divider: светлый в тёмном режиме и тёмный в светлом. Aurora получает lightMode, остальные эффекты — текущую палитру без размонтирования по сезону/режиму.

Из описательных блоков главной, «Ваш рабочий набор», примеров, шагов и справочных блоков убраны декоративные иконки. Функциональные элементы навигации/действий и значки выбранного состояния остаются. У поля отдельного цвета убраны рамка и обводка образца; фокус/ошибка остаются видимыми.

## Ручная приёмка

Проверки агентом не запускались. Проверить пользователю:

1. Восемь сочетаний сезона/режима через шапку и /settings, переходы и перезагрузку. Сезон не сбрасывается при переключении режима.
2. Все страницы, меню, мобильный Sheet и контактный Dialog: контраст, поверхности, границы, фокус, hover, disabled, сообщения/прогресс.
3. Aurora/фон, reduced motion, клавиатуру, 320/390 px, отсутствие лишних декоративных иконок.
4. Старую запись без mode, повреждённый/недоступный storage.
5. Поле цвета без рамки: HEX, picker, непрозрачность и видимый фокус.
6. Независимость предпросмотра редактора, черновика, копий и CSS/JSON от оформления сайта.
