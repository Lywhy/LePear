# Изображения главной — MYT-49

На главную добавлены три сгенерированных материала с единой предметной фотографической стилистикой. Они представляют три инструмента без новых декоративных иконок и ложных работающих контролов.

## Карта размещения

| Место                                       | Материал                                          | Назначение                                         |
| ------------------------------------------- | ------------------------------------------------- | -------------------------------------------------- |
| Карточка редактора в «Что сделаем сегодня?» | Цветовые образцы, матовые пластины и линейка      | Цвет, форма и точность настройки                   |
| Карточка YouTube                            | Наушники, микрофон и пустая кинохлопушка          | Видео и аудио; форматы поясняет текст карточки     |
| Карточка конвертера                         | Виниловая пластинка, фотографии и прозрачная дуга | Работа с музыкой и изображениями                   |
| Первый экран                                | Прежний пейзаж проекта, в двух WebP-размерах      | Сохранение принятого образа с адаптивной загрузкой |

Каждая новая иллюстрация используется в одном месте; статичный обзор инструментов не дублирует фотографии. Подписи, ссылки и описания — HTML, не часть изображения. Высота превью остаётся одинаковой: 16rem (12rem изображение + 4rem подпись). Фото вписывается в рамку на узких/промежуточных экранах; на desktop используется центрированное заполнение карточки.

## Файлы и загрузка

Все используемые ресурсы находятся в public/assets/landing, а не в служебном каталоге генератора.

| Файл                                          | Размер                |
| --------------------------------------------- | --------------------- |
| theme-v1-640.webp / theme-v1-960.webp         | 34 972 / 74 952 байта |
| media-v1-640.webp / media-v1-960.webp         | 29 704 / 59 822 байта |
| converter-v1-640.webp / converter-v1-960.webp | 35 134 / 67 126 байт  |
| hero-v1-768.webp / hero-v1-1440.webp          | 38 640 / 116 458 байт |

Новые изображения перекодированы FFmpeg в WebP quality 82, без метаданных, шириной 640/960. Пейзаж подготовлен из прежнего lepear-landscape.webp с quality 80; оригинал не заменялся. Это подготовка рабочих медиафайлов, а не запуск проверок приложения.

landing-images.ts хранит пути, alt и подписи; LandingImage переиспользует img с srcSet/sizes, width/height, loading=lazy и decoding=async. Фиксированная рамка резервирует место до загрузки, при ошибке остаётся осмысленная текстовая подложка. Верхний декоративный пейзаж — img с пустым alt, eager/high fetch priority и своими responsive-версиями; его отсутствие оставляет цветной фон секции и читаемый контент.

Материалы в нейтральных цветах, поэтому не требуют отдельной загрузки четырёх сезонных копий. Поверхности/подписи используют сезонные токены для светлого/тёмного режима. Существующие Motion/React Bits остаются, новые циклы движения и зависимости не добавлялись.

## Происхождение

Встроенная генерация image_gen, три отдельных промпта, без сторонних фото и референсов. [Полный набор промптов и происхождение](landing-image-prompts.md). PNG-копии для дальнейшего редактирования — work/landing-image-sources, исключены Git; в репозиторий идут финальные WebP. Прежний пейзаж — существующий ресурс проекта, здесь только его новые размерные варианты.

## Ручная приёмка

Сборка, линтер, тесты и браузерные/визуальные проверки агентом не запускались. Пользователю проверить:

1. Три разных изображения в карточках, равную высоту превью, подписи/ссылки и отсутствие ложных интерактивных элементов.
2. Ширину 320/390 px, промежуточный и большой экран: вписывание/кадрирование, отсутствие горизонтального скролла.
3. Все четыре сезона в светлом и тёмном режимах: фото не спорят с оболочкой, подписи читаются.
4. Медленную сеть: зарезервированное место, ленивую загрузку нижних фото и немедленную загрузку верхнего пейзажа; в Network выбираются подходящие responsive-версии.
5. Отключённое изображение/ошибку запроса: подложку, доступность описания, сохранность действий.
6. Клавиатуру и reduced motion: изображения не перехватывают фокус, декоративные эффекты не обязательны для работы страницы.

Размеры файлов указаны по результату подготовки ресурсов. Показатели загрузки, LCP/CLS или ускорение страницы не измерялись и не объявляются проверенными.
