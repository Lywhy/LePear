# MYT-26: выразительнее в исходном стиле

## Согласованное направление

Пользователь отклонил бумажную светлую основу и выбрал шрифтовой вариант 02. Реализация продолжает исходный тёмный вариант LePear: природный пейзаж, Aurora, тёмные зелёные поверхности и лаймовый акцент.

Крупные заголовки оболочки используют Arial Black с fallback Arial/sans-serif. Основной текст остаётся Geist. Arial Black берётся с устройства, поэтому на устройствах без него форма заголовков будет отличаться. Настройки шрифта пользовательской темы независимы от шрифтов оболочки. Новые пакеты шрифтов и движки анимации не установлены.

Отклонённый dev-образец /design-direction удалён вместе с маршрутом. Актуальный результат находится на обычных /, /editor и /contact.

## Композиция

- Hero: асимметричная сетка, крупный трёхстрочный заголовок слева, отдельный визуальный этюд темы справа. Пейзаж/Aurora сохранены. На мобильном колонки складываются в последовательность.
- Этюд — статичная композиция букв, палитры и подписей. Он не заменяет рабочий редактор и не содержит действующих настроек. Большой макет редактора ниже также остаётся статичным.
- Возможности: цвет занимает широкий блок с двумя колонками; типографика/форма — два меньших блока. Сохранён SpotlightCard, без трёх одинаковых по структуре колонок.
- Числовая линейка: 2 палитры, 4 пресета, 7 семейств — реальные возможности текущего редактора.
- Шаги: последовательный маршрут с крупной нумерацией и разделителями вместо четырёх одинаковых карточек.
- FAQ и финальный CTA поддерживают выбранную заголовочную типографику; CTA выровнен по левому краю.
- Редактор: выбранная типографика применяется к заголовкам оболочки; шапка рабочего пространства перестроена в сетку. Поля, модель, хранение, импорт/экспорт и preview не изменены.
- Контакты: новая заголовочная пара, небольшая корректировка пропорций колонок и появления при прокрутке. Demo-режим и поведение формы сохранены.

## Эффекты

Существующие Aurora/SpotlightCard дополнены локальными сокращёнными адаптациями React Bits CountUp и TiltedCard. Исходные URL указаны в файлах; лицензия сохранена.

- TiltedCard используется только для hero-этюда. Мягкий наклон указателем на Motion springs, без flip/гироскопа/постоянного floating. useDecorativeMotion отключает реакцию на мобильном, при reduced motion, вне видимой области/вкладки.
- CountUp анимирует целые значения числовой линейки один раз при появлении. Скринридеру доступно финальное число, а не поток промежуточных значений. Reduced motion — статичное значение.
- ScrollReveal: однократные 24 px и opacity 0.82 → 1 за 700 мс; в последовательности шагов задержки 0/50/100/150 мс. Контент видим до запуска эффекта. При reduced motion смещение/прозрачность сразу финальные.
- Макет редактора на главной появляется при прокрутке. Контакты используют ScrollReveal, сообщения формы сохраняют короткий отклик.
- Новые scroll-эффекты не оборачивают интерактивное preview редактора. Изменение полей не запускает анимацию их раскладки и не перемонтирует примеры.

AnimatedContent был изучен через MCP, но требует GSAP; он не добавлен. Используется уже установленный Motion.

## Приёмка пользователем

1. Главная на desktop/320/390 px: исходная тёмная палитра, читаемость шрифта 02, новый баланс hero/этюда/макета, широкий цветовой блок и линейные шаги.
2. Прокрутка: плавные однократные появления, читаемость до эффекта, отсутствие повторного проигрывания при обычном вводе.
3. Этюд наклоняется только на подходящем desktop. С reduced motion/на мобильном остаётся статичен; Aurora сохраняет прежний fallback.
4. Числовая линейка показывает 2/4/7. Проверить reduced motion и доступность чисел.
5. /editor: шрифты оболочки меняются отдельно от темы, сохраняются HEX-черновики, слайдеры после сброса, копии, ввод витрины и импорт/экспорт. Заголовки групп без hover-подсветки.
6. /contact: типографика, мобильная композиция, ошибки и предпросмотр без отправки.
7. Навигация, мобильное меню, Tab/фокус и отсутствие общего горизонтального переполнения.

Сборка, линтер, тесты и браузерная/визуальная проверка агентом не запускались. Результат передаётся на ручную приёмку; MYT-26 не закрывать до принятия.

## Дополнение: связи, фон и анимации текста

По дополнительному референсу пользователя (AI Customer Notification Platform на Behance) добавлена секция ThemeJourney: четыре разнесённых узла, тонкие соединительные линии с однократным световым проходом, карточки с верхним градиентом/световой кромкой и статичные мини-примеры. На мобильном схема складывается в обычную последовательность без соединительных линий. Чужие изображения и графический цветок не переносились.

Новые React Bits TS-TW получены из официального реестра через shadcn MCP и JSON:

- ShinyText — световой проход по акцентным словам hero/CTA. trigger=view, без постоянного loop/дублирующего glow. AccentText учитывает viewport, мобильную ширину, скрытую вкладку и reduced motion.
- BlurText — раскрытие отдельных заголовков возможностей/маршрута/контактов по словам. Небольшие blur/сдвиг, исходная прозрачность 0.65, без loop. Доступное полное название сохраняется для скринридера. При reduced motion RevealText показывает простой span. Корень адаптирован к span для валидного вложения в заголовки.
- ShapeGrid — фоновая геометрия на Canvas 2D, без дополнительного WebGL. Сетка 96 px, DPR 1, скорость 0.12, без rainbow/clickCascade/intro. Lazy-монтирование только при useDecorativeMotion. Подложка содержит мягкие зелёные/холодные свечения и статичную сетку, которые остаются без canvas.
- Запись settings/callback refs перенесена в эффекты; ShinyText/ShapeGrid получили паузу при скрытой вкладке и cleanup подписок/RAF. Зависимости не добавлялись, лицензия сохранена.

SiteBackdrop расположен только в оболочке, не перехватывает pointer events. Рабочие поверхности редактора остаются читаемыми и независимыми; эффект не входит в модель или экспорт. Превью главной остаётся статичным, движения в мини-примерах декоративные и не меняют тему.

Дополнительно пользователю проверить:

1. Главную с полной прокруткой: ShinyText на акцентах, BlurText в заголовках, новые связанные блоки и световой проход линий.
2. Фон в промежутках между секциями и вокруг рабочих поверхностей: сетка/свечение заметны, текст не теряет контраст.
3. Reduced motion, мобильный вид и скрытие/возврат вкладки: статичная подложка, отсутствие непрерывных циклов; меню/клавиатура/фокус доступны.
4. Заголовки читаются скринридером один раз, длинные слова не расширяют страницу.
5. На менее мощном устройстве оценить плавность прокрутки/ввода в редакторе. Показатели производительности заранее не заявляются.

Сборка, линтер, тесты и браузерная/визуальная проверка не запускались; выполнено только форматирование.
