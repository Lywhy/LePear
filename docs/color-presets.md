# Цветовые пресеты редактора — MYT-47

Каталог /editor расширен с четырёх до 16 пресетов:

- Лес, Океан, Слива, Графит — прежние ID, палитры и поведение сохранены.
- Янтарь — медовый акцент и тёплые каменные поверхности.
- Терракота — глиняный акцент и персиковые оттенки.
- Роза — малиновый акцент и розовые поверхности.
- Лаванда — прохладный барвинковый акцент.
- Мята — бирюзовый акцент и мятные поверхности.
- Кофе — кофейный акцент и сливочные тона.
- Песок — приглушённый оливковый акцент и песочные нейтрали.
- Неон — яркий циановый акцент на прохладной графитовой основе.
- Осень, Зима, Весна, Лето — сезонные варианты по оформлению самого LePear.

Каждый вариант содержит полные светлую и тёмную палитры, включая поверхности, текст, основной/вторичный акценты, границы, поля, фокус и ошибку. Для новых вариантов используется типизированный конструктор полных палитр в src/lib/additional-color-presets.ts; он не наследует случайные цвета исходного «Леса». Общий каталог остаётся в src/lib/theme-palettes.ts.

## Выбор

Вместо длинной сетки кнопок используется установленный Base UI Select с принятым стилем оболочки. Список ограничен по высоте и прокручивается, управляется клавиатурой. У каждого пункта есть образцы фона, карточки, основного цвета и текста для выбранного режима. Под списком — текущие цвета, описание выбранного пресета и пояснение действия.

Выбор заменяет все цвета только активного режима одним обновлением; второй режим, типографика, размеры и сохранённые копии не меняются. Совпадение с пресетом определяется по всем цветам, после ручной правки появляется «Своя палитра». Для повторного применения после ручных изменений выберите пресет снова.

Пресеты — содержимое пользовательской темы, а четыре сезона в /settings — оболочка LePear. Эти настройки независимы. Schema v2, storage keys и формат CSS/JSON не менялись; ID пресетов не становятся обязательным полем сохраняемой темы. Существующие подсказки контраста продолжают работать, новые палитры не объявляются заранее проверенными на все сочетания.

## Ручная приёмка

Проверки агентом не запускались. Пользователю проверить:

1. В /editor открыть «Цвета», увидеть 16 вариантов, прокрутку и образцы; выбрать варианты мышью и клавиатурой, проверить длинное имя и ширину 320/390 px.
2. Применить каждый новый пресет в светлом и тёмном режимах. Оценить текст/поверхности, основные и вторичные кнопки, формы, меню/диалоги, ошибки и фокус; обратить внимание на подсказки контраста.
3. Перед выбором изменить шрифт/размеры и цвета другого режима. После применения они должны сохраниться.
4. Изменить один цвет вручную: должна появиться «Своя палитра». Повторно выбрать пресет и вернуть все цвета активного режима.
5. Сохранить копию, сменить пресет, восстановить копию, перезагрузить; проверить JSON-импорт/экспорт и CSS.
6. Старые Лес/Океан/Слива/Графит и ранее сохранённые темы остаются совместимыми. Переключение сезонов LePear не меняет пользовательскую палитру.

## Сезонные варианты

src/lib/seasonal-color-presets.ts формирует четыре пресета со стабильными ID season-autumn/winter/spring/summer. Оба режима берут текущие значения сезонного оформления LePear: тёмные из shell-seasons.ts, светлые из light-shell-palettes.ts. Преобразование создаёт отдельные палитры редактора. Это отдельные объекты ThemePalette: выбор пресета не выбирает сезон приложения и наоборот. Применение затрагивает только активный режим, как у остальных пресетов.

## Поле отдельного цвета

ColorField вынесен в переиспользуемый компонент. Общая рамка объединяет кликабельный образец с подложкой для прозрачности, системный picker и HEX. Вставка допускает решётку или её отсутствие и смешанный регистр; короткие 3/4-значные формы разворачиваются в 6/8-значные при Enter или выходе из поля. Полные корректные цвета применяются сразу; неполный ввод остаётся черновиком без немедленной ошибки. Некорректный ввод не меняет тему, ошибка появляется при подтверждении. Escape восстанавливает последний корректный цвет.

Для параметров, допускающих альфа-канал, раскрывается «Непрозрачность» с ползунком 0–100%. Процент связан с последними двумя символами HEX; системный picker меняет RGB и сохраняет текущую альфу. Основной акцент остаётся непрозрачным по модели редактора. Base UI Slider получает подпись и процент для своего thumb через необязательные thumbProps; прежнее поведение остальных ползунков сохраняется.

Дополнительно вручную проверить четыре сезонных пресета в обоих режимах и независимость сезона оболочки; ввод #F90, F90, 112233 и 11223380, неполный/неверный текст, Enter/blur/Escape, системный picker, альфу 0/50/100%, клавиатуру, восстановление после пресета/сброса и экспорт. Проверки агентом не запускались.

В MYT-53 рамка поля цвета и обводка его образца убраны по запросу пользователя; клавиатурный фокус и индикация ошибки сохранены. Обновление цветов сайта не переписывает ранее сохранённые темы: новые значения попадают в редактор при явном повторном применении сезонного пресета.
