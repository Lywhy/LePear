# Палитра оболочки — MYT-35

Источник — изображение горного заката в hero. Тёмные угольные и коричневые оттенки формируют основу, оранжевый свет — основной акцент, кремовые облака — текст, медный и персиковый — дополнительные оттенки. Зелёные оттенки оболочки заменены тёплой оранжевой гаммой.

Единый источник значений — src/lib/shell-palette.ts. Перед монтированием React устанавливаются наследуемые переменные оболочки. В index.css только регистрации цветов @theme inline для семантических Tailwind utilities bg-shell-_, text-shell-_, border-shell-* и других. Новых CSS-селекторов для компонентов не добавлено.

shadcn-значения оболочки применены к SiteLayout и портальным Sheet/Dialog; shared controlClasses используют те же Tailwind-цвета для Select. Переменные установлены на documentElement, поэтому доступны порталам вне корня React. Акценты Canvas/WebGL читают реальные HEX из того же источника.

## Границы

Изменены оболочки главной, редактора, YouTube и контактов: фоны, текст, действия, формы, меню, панели, ошибки и прогресс. Статичные иллюстрации главной согласованы с Sunset / Dark. Aurora/Spotlight/ShapeGrid меняют только цвета; их жизненный цикл и анимации — следующие issues.

Макет редактора на главной получает отдельный landingPreviewTheme, созданный независимым createInitialTheme(). Он не записывается в workspace или storage. Рабочая модель темы, пресеты, createInitialTheme, сохранение, импорт/экспорт, ThemePreview и его галерея не изменялись. Живая витрина по-прежнему показывает пользовательские значения. Arial Black / Geist и размеры блоков сохранены.

## Ручная приёмка

1. Открыть главную: общий фон, текст и янтарные действия согласованы с изображением. Проверить hero, статичный макет, блоки «Цвет», типографики/формы, шаги, FAQ и CTA.
2. На /editor проверить оболочку панели, Select и слайдеры. Живая витрина должна остаться в выбранной пользовательской теме; переключить светлый/тёмный режим и импортировать ранее сохранённый JSON.
3. На /youtube получить данные, открыть списки трёх режимов, проверить активные вкладки, прогресс, ошибки/disabled и таймер 429. Поведение скачивания прежнее.
4. На /contact проверить поля, сообщения и диалог предпросмотра. Открыть мобильное меню с каждой страницы.
5. На 320/390 px и desktop проверить читаемость основного/приглушённого текста, focus/hover/disabled и порталы. При reduced motion сохраняется оформленный статичный фон.
6. Сравнить экспорт пользовательской темы с её настройками: акцент оболочки не должен попадать в него сам по себе.

Сборка, линтер, тесты, браузерные/визуальные проверки и API агентом не запускались. Результаты ожидают ручной приёмки пользователя. Следующий issue MYT-36 начинается после принятия палитры.
