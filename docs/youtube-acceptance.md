# YouTube: единая ручная приёмка MYT-33

Сценарий выполняет пользователь. Результаты заранее не проставлены. Сборка, линтер, тесты, API, браузер и скачивания агентом не запускались.

## Подготовка

1. Запустить API и Vite в отдельных терминалах. После серверных изменений перезапустить pnpm api, обновить страницу.
2. Подготовить публичный короткий ролик с отдельными аудиопотоками и субтитрами, ролик без субтитров и недоступный ролик. Не использовать материалы, требующие авторизации/обхода ограничений.
3. Сохранить резервный JSON темы редактора, если он нужен. Проверять перенос между страницами на том же origin.
4. Открыть /youtube напрямую и через навигацию. На короткой странице footer должен быть у нижней границы окна.

## Основной путь

1. Вставить watch/youtu.be/Shorts-ссылку, получить данные. Проверить название, канал, обложку, длительность и реальные списки. Во время загрузки «Очистить» отключена, отмена доступна.
2. На вкладке «Видео» по умолчанию — «Лучшее качество» с конкретным потоком ниже. Выбрать качество в пределах лимита, скачать MP4; проверить имя, видео и звук. Повторить для WebM и раздельного видео/аудио.
3. Во вкладке «Аудио» сразу выбрать M4A/Opus и скачать. Предварительная загрузка видео не нужна. Проверить отсутствие видео, затем MP3 и отдельный этап конвертации.
4. Во вкладке «Субтитры» проверить язык, авторский/автоматический источник, прямой VTT и SRT с конвертацией. Проверить кириллицу, таймкоды, имя с языком/источником. Если доступен исходный SRT, проверить и его преобразование в VTT.
5. На ролике без субтитров ожидается сообщение и отключённая кнопка. При отсутствии отдельного аудио — понятное ограничение.
6. Готовый файл автоматически передаётся браузеру; сайт не объявляет сохранение на устройство завершённым. Повторная кнопка скачивает готовый файл, если выбор не изменён.

## Отмена, повтор и жизненный цикл

1. Быстро нажать «Скачать» дважды: не должно быть двух созданий. Выбор параметров заблокирован на время обработки.
2. Отменить на подготовке, загрузке и конвертации. Пока отмена отправляется, кнопки заблокированы; затем можно повторить. Проверить очистку временного каталога.
3. Изменить/очистить ссылку во время скачивания, перейти на другую страницу. Старый результат не должен появиться у новой ссылки.
4. Закрыть/перезагрузить вкладку с активной работой. При повторном открытии ничего автоматически не запускается. Если браузер не доставил отмену, задание ограничено серверным тайм-аутом.
5. Повторно нажать «Скачать» для готового файла несколько раз быстро: параллельные проверки одного результата блокируются.
6. Дождаться TTL или удалить результат через его API. Повторное сохранение объясняет недоступность; следующее нажатие создаёт новый файл.
7. Перезапустить API при готовом результате на странице. Прежний результат недоступен, но можно скачать заново.

## Сбои и ограничения

1. Выключить API до запроса метаданных и во время опроса задания. Должна быть понятная конечная ошибка, без бесконечного индикатора. После запуска повторить.
2. Прервать сеть при отмене: интерфейс сообщает, что отмена не подтверждена. После восстановления повторить отмену/скачивание.
3. Проверить недоступный ролик, исчезнувшую дорожку/формат, отсутствие инструмента и ошибку конвертации. Не должен выдаваться ложный успех или файл неправильного режима.
4. Временно уменьшить лимит размера/времени/TTL в .env, перезапустить API и проверить ограничения, очистку и повтор. После проверки вернуть настройки.
5. Проверить общий лимит задания при переходе между вкладками: второе задание не создаётся поверх первого.
6. При HTTP 429 субтитров проверить таймер и блокировку; при перезапуске API пауза сохраняется. Новое нажатие во время паузы не должно обращаться к YouTube. Не создавать искусственно много запросов ради этого сценария.
7. Открыть URL задания/файла в приватном окне: ожидается 404, без доступа к чужим данным. После TTL файл недоступен.

## Экран и доступность

Повторить основные состояния на desktop и ширинах 320/390 px:

- Нет горизонтального скролла; длинные заголовки, языки и имена файлов переносятся.
- Select и кнопки доступны с клавиатуры, подписи связаны с полями, фокус виден.
- Статусы этапов озвучиваются; проценты не имитируются для неизвестного размера/конвертации.
- Во время проверок/обработки disabled-состояния понятны.
- При reduced motion анимации не мешают содержимому.
- Мобильное меню, footer и общая палитра совпадают с LePear.

## Регрессия существующих страниц

1. Главная: статичное превью, равные половины блока «Цвет», переходы и раскрытие FAQ.
2. Редактор: палитры двух режимов, типографика/размеры, сворачивание групп, локальное сохранение, JSON/CSS и сброс. Данные темы не должны изменяться от работы с YouTube.
3. Контакты: форма и прежнее демонстрационное поведение.
4. Навигация: desktop/mobile, прямые переходы, возврат браузером. Дубликаты header и активные downloads при повторном открытии не возникают.

Для замечания записать режим, шаг, текст ошибки и код из API/терминала. Не публиковать cookies и подписанные URL. После общего принятия закрываются MYT-33 и родительская MYT-27.
