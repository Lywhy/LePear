# LePear

Визуальный редактор темы сайта на **shadcn/ui Base Nova**. Цвета, типографика и размеры применяются к живому предпросмотру. Тему можно сохранить в браузере, перенести через JSON и подключить к своему сайту через CSS.

Реализация этапов MYT-6–MYT-13 принята пользователем. Итоговая приёмка всего MVP (MYT-14) ещё ожидается: результаты старых проверок не подтверждают текущую версию.

## Запуск

Нужны Node.js, совместимый с Vite 8, и pnpm. Из корня проекта:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес из терминала Vite. По умолчанию порт 5173; при занятом порте он может измениться. Для восстановления локальных тем используйте тот же протокол, домен и порт.

| Команда | Назначение |
| --- | --- |
| `pnpm dev` | Сервер разработки |
| `pnpm build` | Проверка TypeScript и сборка в `dist/` |
| `pnpm lint` | Oxlint |
| `pnpm preview` | Просмотр сборки после `pnpm build` |

Отдельной команды тестов нет. Команды проверок приведены для ручного запуска пользователем, агентом на текущем этапе не выполнялись.

## Страницы

- `/` — лендинг со статичным макетом редактора, мобильным меню и FAQ.
- `/editor` — рабочий редактор, предпросмотр компонентов, локальные темы, импорт и экспорт.
- `/contact` — демонстрационная контактная форма без отправки сообщений.

## Как создать тему

1. На `/editor` раскройте нужные группы. Их можно сворачивать независимо или все сразу; заголовки показывают текущие значения.
2. Выберите светлый или тёмный режим и пресет: «Лес», «Океан», «Слива» или «Графит». Цвета двух режимов независимы, пресет заменяет цвета только выбранного режима.
3. Измените акцент, поверхности, текст, границы и состояния. Поддерживаются picker и HEX; некорректный ввод не попадает в тему. Подсказки контраста не блокируют выбор.
4. Настройте шрифт, размер, насыщенности текста/заголовков и интервалы. Geist подключён локально с кириллицей; остальные семейства используют шрифты устройства и описанные fallback.
5. Выберите плотность и размеры. Это общие настройки для двух режимов. Высота контролов — минимальная; крупный текст и переносы могут увеличивать её.
6. Оцените широкий/узкий предпросмотр, кнопки, формы, таблицу, Select и Dialog. Действия примеров не меняют реальные данные.
7. В «Мои темы» создайте именованную копию. Рабочие изменения сохраняются автоматически, но именованная копия обновляется только кнопкой «Обновить копию».
8. Скачайте JSON для резервной копии или CSS для подключения к своему сайту.

Отдельные сбросы цветов, типографики и размеров сохраняют остальные параметры. «Сбросить всю тему» восстанавливает рабочую тему, не удаляя именованные копии.

## Сохранение и перенос

Рабочая тема и настройки панели сохраняются в `localStorage` (`lepear.workspace`). Библиотека вмещает до 20 именованных копий с уникальными названиями длиной 1–60 символов. Выбор другой копии заменяет рабочую тему; нужные варианты заранее сохраняйте отдельными копиями. Удаление копии оставляет рабочую тему в черновике.

JSON schema v2 содержит одну тему: обе палитры и общие настройки. Импортируйте файл или вставьте JSON, просмотрите параметры, затем нажмите «Применить тему». Невалидный импорт не меняет состояние. Максимальный размер — 1 МБ. Импорт не заменяет библиотеку именованных копий.

CSS содержит обе палитры, слой токенов **Tailwind v4** и дополнительные scoped-стили компонентов. Подключение требует обработки CSS сборкой, контейнера `.lepear-theme`, согласованных `data-theme`/класса `dark` и размещения порталов внутри контейнера. Шрифтовые файлы экспорт не включает.

[Минимальный пример и инструкция интеграции](examples/theme-integration/README.md).

Копирование CSS/JSON использует Clipboard API. Если оно недоступно, показывается поле ручного копирования; скачивание остаётся доступным.

## Ограничения MVP

- Нет аккаунтов, сервера, синхронизации между устройствами или вкладками. При работе нескольких вкладок последняя запись выигрывает.
- Данные зависят от браузера и origin; очистка данных сайта удаляет локальные темы. JSON резервирует одну тему, не всю библиотеку.
- При ошибке хранилища работа продолжается в памяти. Скачайте JSON и повторите сохранение после восстановления доступа.
- Повреждённые/устаревшие данные открываются с исходной темой и предупреждением. Старая запись не заменяется до явного действия пользователя. Автоматической миграции старых схем нет.
- Черновики ошибочного HEX, названия копий до сохранения и состояния демонстрационных форм не восстанавливаются.
- Системные шрифты и их начертания зависят от устройства; используются fallback.
- Подсказки контраста не заменяют полную проверку доступности, состояний и прозрачных наложений.
- Для собственных блоков используйте экспортированные токены или классы `lepear-stack`/`lepear-grid`. Сторонние компоненты могут требовать адаптации.

Размещение приложения согласуется отдельно. Для статического хостинга потребуется SPA fallback на `index.html`, чтобы прямые переходы на `/editor` и `/contact` работали. Публикация и выбор хостинга пока не выполнялись.

## Разработка и приёмка

Стек: React 19, TypeScript 6, Vite 8, Tailwind CSS 4, shadcn/ui Base Nova, React Router, React Compiler, Oxlint, pnpm. Alias `@` указывает на `src`. Точные версии — в `package.json` и `pnpm-lock.yaml`.

Основные файлы: `src/pages/editor.tsx`, `src/components/editor/`, `src/components/preview/`, `src/lib/site-theme.ts`, `src/lib/use-theme-workspace.ts`, `src/lib/theme-transfer.ts`. Компоненты оформляются Tailwind-классами; отдельного `landing.css` нет. Реестры React Bits и ReUI настроены в `components.json`.

Разработка идёт по [Linear](https://linear.app/mythme/issue/MYT-5), по одной задаче с приёмкой пользователя. Согласованный порядок проверок описан в `AGENTS.md`: агент не запускает сборку, линтеры, тесты или браузерную проверку без отдельной просьбы.

[Сценарий итоговой ручной приёмки](docs/manual-acceptance.md). Это инструкция с ожидаемым поведением, а не отчёт о пройденных проверках.

[Исторические заметки по реализации](docs/development-notes-before-myt14.md) и `design-qa.md` относятся к прошлым этапам и могут содержать устаревшие статусы/результаты. Для текущих возможностей используйте этот README.
